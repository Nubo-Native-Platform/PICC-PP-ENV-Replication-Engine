# Contributing to Nubo Native Platform (NNP)

This repository — **PICC - PP - Environment Replication Engine** — is part of the **Platform Portal (PP)** suite under the **Platform Infrastructure and Core Components (PICC)** area of the Nubo Native Platform. Contributions are welcome under the **Apache 2.0 License**.

## Before you start
Contribute against an open **Issue**, the published **Roadmap**, or a proposed **enhancement**. Email **contribution@nubons.com** with your approach and category first; we respond within 5 working days.

## Steps
1. Fork & clone.
2. Make a focused change on a feature branch (`feat/...`, `fix/...`, `docs/...`).
3. Ensure code compiles cleanly with `./mvnw clean test` and passes SpotBugs checks (`./mvnw spotbugs:check`).
4. Note the testing in the PR.
5. Open a Pull Request with a clear description adhering to conventional commits.

## Security
**Never commit secrets, tokens, `.env` files, internal infrastructure IPs, or credentials.** See [SECURITY.md](SECURITY.md). All participation is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
